# 🇮🇳 ElectionSaarthi

**ElectionSaarthi** is an interactive, open-source web application designed to help Indian citizens understand the election process, timelines, and voting procedures in an intuitive and visually engaging way.

## 🌟 Features

- **Interactive Timeline**: A dynamic visual timeline detailing the key phases of the election process, from the Model Code of Conduct to Results Day.
- **Voter Guide**: A step-by-step guide explaining how to check eligibility, register to vote, and obtain a Voter ID.
- **ElectionSaarthi Assistant**: An interactive FAQ section that answers common questions regarding VVPAT, MCC, NOTA, and alternative ID documents.
- **Modern UI/UX**: Built with a sleek glassmorphism aesthetic, incorporating the Indian national colors (Saffron, White, Green, and Navy Blue) for a premium, unique experience.
- **Fully Responsive**: Optimized for seamless viewing on mobile, tablet, and desktop devices.

## 🛠️ Technology Stack

- **Frontend Framework**: React (via Vite)
- **Styling**: Vanilla CSS with CSS variables for custom theming and responsive design (No external CSS frameworks used).
- **Typography**: Inter and Outfit (Google Fonts)

## 🚀 Getting Started

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/HimangshuYadav/ElectionSaarthi.git
   cd ElectionSaarthi
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173/`
